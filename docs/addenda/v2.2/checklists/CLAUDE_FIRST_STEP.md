# Primeiro passo recomendado para Claude Code

1. Verificar branch, SHA, árvore e status do repositório.
2. Carregar v2.1 e o adendo v2.2 sem sobrescrever.
3. Preencher tabela de gaps e ADRs (versão real versus desejada).
4. Registrar issues FC22 no backlog existente, com dependências e flags.
5. Propor PR pequeno apenas com docs/contratos/fixtures e teste de schema.
6. Pedir revisão Codex. Só depois escolher o menor slice de implementação P0.

O agente não deve afirmar que implementou Subscriber 360, scores ou controladores sem testes reais.
