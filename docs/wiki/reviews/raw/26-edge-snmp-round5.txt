  `busy` and `cool` are indexed by `src.Name`. Config validation requires names to be unique, but does not require SNMP addresses to be unique. The same OLT can therefore be configured under two names; concurrent collection runs can reserve each entry independently and send requests to the same rate-limited agent. This defeats the device-level serialization and failure protection, risking another agent mute period and disruption to other monitoring clients.
