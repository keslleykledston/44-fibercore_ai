Não ship ainda: a UI usa o relógio do navegador para decidir se uma fila vazia tem leitura recente, então pode divergir do limite aplicado pela API.

Findings:
- [medium] A idade da leitura é calculada com o relógio do navegador (apps/web/src/app/rede/pendentes/page.tsx:38-42)
  `readFresh` compara `asked_at` com `Date.now()` no navegador, enquanto o endpoint de sync aplica o limite usando o relógio da API. Se o relógio do navegador estiver atrasado, uma leitura que a API já considera velha pode aparecer como recente; com fila vazia, a tela pode afirmar que a leitura não detectou ONUs quando o sync recusaria essa mesma leitura. A idade fracionária corrige o arredondamento, mas não essa divergência entre relógios.
  Recommendation: Calcule a idade no servidor ou use um timestamp/idade emitido pelo endpoint e aplique o mesmo limite inclusivo de 60 minutos usado pelo sync.
