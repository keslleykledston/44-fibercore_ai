A API limita a resposta a 1.000 registros e não há paginação; portanto, qualquer CPE fora desse recorte é tratado como inexistente em `(list.data && !cpe)`, embora as consultas por ID possam encontrá-lo.   As respostas de capacidades são coletadas com `apiSafe`, mas seus status de erro não são apresentados. A tela pode, assim, parecer uma matriz completa apesar de consultas falhadas.
