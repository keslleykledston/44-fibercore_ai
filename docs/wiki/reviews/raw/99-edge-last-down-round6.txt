# Codex Adversarial Review

Target: branch diff against main
Verdict: needs-attention

Do not ship yet: the side channel can overlap a CLI session to the same OLT because it uses a separate guard identity.

Findings:
- [medium] Last-down reads bypass the CLI device lock (agents/edge/internal/collector/olt_lastdown.go:99-100)
  The side channel is guarded under `ld.Key` (`last-down|<device>`), while CLI collection uses the device key itself. Those keys do not share the collector’s per-device busy lock. Since a side-channel run can last up to eight minutes and CLI collection intervals can be shorter, a later collection can open SSH while SNMP is still reading the same OLT. Concurrent access can contend with the device’s rate limits and make either read unreliable. Keep a shared per-device in-flight lock across both transports while retaining separate pacing and cooldown state.
  Recommendation: Use a shared physical-device lock for CLI and last-down I/O, without merging their interval or cooldown state.
