Do not ship: pacing and cooldown state vanish on every Edge restart, so a restart loop can repeatedly log in during the CLI cooldown or interval.

Findings:
- [high] Restarting the Edge resets all OLT pacing protection (agents/edge/internal/collector/olt.go:45-55)
  The lock, last-attempt timestamp, and cooldown deadline exist only in this `OLT` instance’s in-memory maps. A process restart recreates them empty, allowing the first collection after every restart to immediately open a new CLI session—even if the previous attempt failed moments earlier or a successful collection just ran. A crash/restart loop can therefore defeat both the 15-minute interval and failure cooldown and repeatedly hit the shared account. Persist per-device attempt/cooldown state across restarts, or implement an equivalent restart-safe mechanism before dialing.
  Recommendation: Store the last-attempt and cooldown deadlines durably under a canonical device key, and load/check them before any OLT I/O; add a test that constructs a fresh collector after a failed attempt and verifies it does not dial during cooldown.
- [medium] CLI and SNMP entries for the same OLT use different guard keys (agents/edge/cmd/fibercore-edge/main.go:87-108)
  The CLI key is derived from `o.Address` (typically `IP:22`) while the SNMP key is derived from `o.SNMPAddress` (typically `IP:161`). Those keys differ for one physical OLT, and validation only deduplicates SNMP addresses; it permits a CLI entry and SNMP entry for the same device. Concurrent `Collect` calls can therefore pass the per-key busy check and access that device simultaneously. This defeats the stated physical-device serialization across transports under the overlapping periodic/job path. Use one transport-independent canonical device identity and reject conflicting duplicate device entries where identity cannot be established.
  Recommendation: Define a canonical physical OLT key shared by CLI and SNMP configuration, validate duplicate physical devices across transports, and add a concurrent mixed-transport test proving only one collection can reach the device.
