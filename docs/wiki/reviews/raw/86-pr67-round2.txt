# Codex Adversarial Review

Target: branch diff against main
Verdict: needs-attention

Do not ship: Exclusive inherits the OLT’s collection cooldown for its reservation and pre-login failures, so configurations below 15 minutes bypass the stated default protection.

Findings:
- [high] Bench reservations and login failures can use the OLT’s shorter configured cooldown (agents/edge/internal/collector/olt.go:106-119)
  `Exclusive` passes the configured `OLTSource` into `guarded` without overriding its `Cooldown`. The guard uses that value both for the pre-I/O reservation and as the fallback cooldown when `opened()` was never called. Since regular OLT `cooldown_seconds` accepts values as low as 60 seconds, a bench attempt can persist only that short reservation before login; a crash or failed login then leaves the shared collector eligible to retry after that shorter interval, contrary to the required 15-minute default. Set the bench reservation and pre-login failure fallback explicitly to the 15-minute CLI default, while applying the configured bench cooldown only after `opened()`.
  Recommendation: In `Exclusive`, give the guard a 15-minute cooldown for the pessimistic reservation and failures before `opened()`. Keep the configured shorter duration isolated to post-login failures, and cover this with a source configured for a shorter general OLT cooldown.
