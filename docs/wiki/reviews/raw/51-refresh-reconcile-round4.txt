Findings:
- [high] A janela não cobre listagens não vazias sem o ID retornado (agents/edge/internal/nbi/refresh.go:229-237)
  Quando `knownID` existe, o código faz uma única listagem. Se ela contém uma tarefa de mesmo formato que não seja a tarefa retornada, falha fechado; porém, se ela não contém candidata alguma, também falha imediatamente por `found == false`, sem repetir a consulta. A tarefa própria pode ainda estar propagando enquanto uma tarefa alheia aparece, exatamente a situação em que as novas consultas deveriam resolver a ambiguidade. Isso causa retenção desnecessária e deixa o caso de consistência eventual do ID sem cobertura pelos testes. Repita a busca do ID dentro da janela limitada antes de concluir que ele não está listado, preservando falha fechada se outro look-alike impedir atribuição.
  Recommendation: Aplicar a janela de consultas também ao ramo `knownID`: aguardar/relistar quando o ID estiver ausente e só falhar após o limite; adicionar teste em que a tarefa retornada aparece numa consulta posterior.
