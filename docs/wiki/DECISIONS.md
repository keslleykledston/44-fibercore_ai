O operador só PEDE (suspensa, não demo, carência de 7 dias, cancelável; reativar cancela); o dono exporta (`org-export`, sem coluna de segredo) e apaga (`org-close`, nome exato + arquivo do export com o mesmo sha256 + dados iguais ao exportado, uma transação, tabelas descobertas pelo catálogo); fica só um registro mínimo permanente sem dado de cliente final.
- D-0051 (2026-11-14): ADR-0051 — tokens de API (só leitura, lista fechada, só o hash guardado, taxa própria) e webhooks de saída (https, catálogo fechado de eventos, carga só com chaves da lista, HMAC, anti-SSRF com conexão ao IP validado); SSO proposto e NÃO construído (precisa de IdP real e ADR de risco próprio).
